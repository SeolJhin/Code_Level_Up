======================================================

코딩 테스트 대비와 알고리즘 학습 과정을 기록하는 저장소입니다.

프로그래머스, 코드트리, SWEA, LeetCode, Codeforces 등 여러 온라인 저지에서 해결한 문제와 학습 내용을 사이트별로 정리합니다.

## 학습 목표

- 자료구조와 알고리즘의 기본 원리 이해
- 문제 유형별 해결 방법 학습
- Java를 활용한 코딩 테스트 구현 능력 향상
- SQL 코딩 테스트 대비
- 풀이 과정과 실수 기록을 통한 반복 학습
- 시간 복잡도와 공간 복잡도를 고려한 코드 작성

## Problem Naming Convention

문제 파일은 사이트 식별자, 문제 번호, 문제 이름을 기준으로 작성합니다.


사이트식별자_문제번호_문제이름.java

[
예시:


P42586_기능개발.java
LC0003_LongestSubstringWithoutRepeatingCharacters.java
SWEA1208_Flatten.java
CF4A_Watermelon.java
]

## 사이트 제출 형식에 따라 파일명과 클래스명이 다를 수 있습니다.

* 프로그래머스: `programers`
* SWEA: `swea` 또는 사이트 지정 클래스
* LeetCode: `leetCode`
* Codeforces: `codeForces`
